## 🏛️ Flagship Ventures & Ecosystem

### 💼 Commercial Operating Systems (`venture/*`)
- **[Agency-OS](https://github.com/1nsharma-labs/agency-os)**: The complete business operating system for digital agencies, dev shops, and freelance software engineers. Client onboarding, scope proposals, milestone Kanban, 18% GST tax invoicing, and direct UPI settlement.
- **[Restaurant-OS](https://github.com/1nsharma-labs/restaurant-os)**: Open-source restaurant, cafe, and cloud kitchen operating system with zero-commission QR menus, KDS, and direct table UPI settlement.
- **[Course-OS](https://github.com/1nsharma-labs/course-os)**: Open-source interactive learning and course platform with in-browser code labs, invariant testing, and verifiable certificates.

- **[Bharat-GST-Billing](https://github.com/1nsharma-labs/bharat-gst-billing)**: Free, offline-first open-source GST billing and invoice engine for Indian SMB merchants, freelancers, and dev shops.
- **[UPI-PG](https://github.com/1nsharma-labs/upi-pg)**: Open-source zero-fee UPI payment gateway and webhook callback handler for Indian online businesses.
- **[OmniMCP](https://github.com/1nsharma-labs/omnimcp)**: Universal Model Context Protocol (MCP) hub and autonomous agent workspace for desktop, mobile, and CLI.
